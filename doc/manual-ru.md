# MacHPSDR — Руководство пользователя (русский)

MacHPSDR — приложение управления SDR на GTK для оборудования HPSDR (ANAN, Hermes,
Hermes-Lite 2, Orion, …) и устройств SoapySDR (RTL-SDR, LimeSDR, HackRF). Это
форк LinHPSDR с упором на macOS. Руководство описывает основные функции в общих
чертах — это не справочник по каждой кнопке.

> Другие языки: [English](./manual-en.md) · [Українська](./manual-uk.md) · [Беларуская](./manual-be.md)

---

## 1. Запуск

```bash
./machpsdr                 # обычный старт — поиск сетевых и USB-устройств
./machpsdr --usb-only      # без сетевого поиска (только USB/SoapySDR)
./machpsdr --faker ft8.wav # без железа: прогон I/Q WAV через тракт приёма
```

При старте MacHPSDR показывает **диалог выбора устройства** со всеми найденными
радио. Выберите нужное, чтобы открыть его. Список всегда завершается пунктом
**«I/Q Player»** — проигрыватель записанного I/Q-файла без оборудования (см. §13);
выберите его, чтобы попробовать интерфейс или воспроизвести запись без радио.
С `--faker` диалог пропускается и I/Q Player запускается сразу.

Запуск `.app`-бандла: двойной клик по `MacHPSDR.app`, либо, чтобы передать флаги,
вызвать лаунчер напрямую
(`MacHPSDR.app/Contents/MacOS/MacHPSDR --faker /абсолютный/путь.wav`). Подробности
в основном README.

## 2. Главное окно

Окно построено сверху вниз вокруг одного или нескольких **приёмников**:

- **Индикатор VFO** — крупное табло частоты с VFO A/B, режимом, фильтром и шагом.
  Это центр настройки каждого приёмника.
- **Панадаптер (спектр РЧ)** — «живой» спектр полосы приёмника. Полоса фильтра
  затенена; курсор показывает точку настройки. Панадаптер можно отключить для
  каждого приёмника (флажок **Show Panadapter** в диалоге настроек приёмника) —
  тогда водопад занимает всю область спектра. В разделе **Panadapter** диалога
  настроек приёмника также есть наложение **Peak Hold** (светлая линия
  удержания максимума со слайдером **Peak Decay** — скоростью спадания
  удержанных пиков), режим **Histogram** — послесвечение (виртуальный люминофор:
  тепловое облако, показывающее, где бывал след, со слайдером **Persistence
  Decay** — скоростью угасания) и выпадающие списки **Detector** / **Averaging**,
  меняющие способ расчёта спектра; всё запоминается для каждого приёмника.
- **Водопад** — прокручивающаяся спектрограмма под панадаптером, раскрашенная по
  уровню сигнала.
- **Нижняя панель** — сгруппированные «модули» управления: выбор диапазона/режима/
  фильтра, AGC, шумоподавление и модуль **SETUP** с Configure, Add Receiver,
  Record и (в DIGU) переключателем FT8-панели.

MacHPSDR намеренно ограничен **2 приёмниками** (пока — это решение ради
интерфейса; сам движок может больше). **Add Receiver** открывает второй блок со
своими VFO, панадаптером и водопадом.

## 3. Настройка и VFO

- **Клик / перетаскивание** по панадаптеру или водопаду настраивает частоту;
  колесо мыши шагает текущим шагом настройки.
- **Настройка прямо на дисплее VFO** — три способа:
  - **Колесо мыши** над цифрой шагает её разрядом: вверх — выше, вниз — ниже
    (одинаково для VFO A/B и в ctun/freetune; цифра под курсором определяется
    точно по тексту).
  - **Наведи на цифру и нажми клавишу-цифру** — она впишется на это место, а
    курсор перейдёт к следующей цифре справа (как в SDR#), так частоту можно
    набрать слева направо.
  - **Левый клик** по частоте открывает окошко ввода, уже заполненное текущей
    частотой в МГц — впиши или поправь её (точка или запятая как разделитель,
    сгруппированный вид `14.074.000` тоже понимается) и нажми Enter, Esc —
    отмена. **Меню выбора банда** — на **правом клике**.
  - Настройка ограничена диапазоном **0–6 ГГц** (или собственным верхним
    пределом устройства, если он ниже), чтобы случайная правка не увела VFO на
    бессмысленную частоту.
- **VFO A / B**, сплит и обмен A↔B — на виджете VFO и нижней панели.
- **Зум** — панадаптер можно приблизить, чтобы рассмотреть узкие сигналы (быстрые
  прыжки ×10/×12/×16/×32 из меню зума VFO). Практический максимум зависит от ширины
  панадаптера (у анализатора WDSP фиксированный внутренний буфер, поэтому очень
  широкое окно автоматически ограничивает зум).
- **Freetune** — плавная непрерывная настройка, добавленная в этом форке.
- **Коррекция PPM и автокалибровка** — корректирует ошибку опорного генератора
  (дробный ppm; применяется одинаково в Protocol 1, Protocol 2 и SoapySDR). Её
  можно измерить автоматически по несущей станции точного времени — см. §10
  (Configure → Display).

## 4. Управление приёмником

- **Режим** — LSB, USB, CWL, CWU, AM, SAM, FMN, DIGU, DIGL и т. д.
- **Фильтры** — предустановки полосы для каждого режима плюс регулируемые нижняя/
  верхняя границы. Дополнительные фильтры-аттенюаторы (att10 / att20) добавлены в
  этом форке.
- **AGC** — off / long / slow / medium / fast, с регулируемым порогом (линия «AGC
  gain» на панадаптере).
- **Шумоподавление** — NR / NR2 / NR3 / NR4 (снижение шума — NR3 это нейросетевой шумоподавитель RNNoise, NR4 — адаптивное спектральное вычитание libspecbleach; выбираются в меню кнопки NR на панели VFO), NB / NB2 (шумоподавитель
  импульсов), ANF (автоматический режектор) и **SNB** (спектральный подавитель
  импульсов). Каждое состояние запоминается по приёмнику между сеансами.
- **Ручные режекторы (MNF)** — расставляйте собственные режекторы, чтобы убрать
  постоянную несущую или гетеродинный свист. **Ctrl+клик** по спектру приёмника
  ставит режектор на этой частоте; **Ctrl+клик** по существующему режектору
  удаляет его. Режектор рисуется полупрозрачной красной полосой с центральной
  линией и хранится по абсолютной частоте, поэтому остаётся на мешающем сигнале
  при перестройке. До 16 на приёмник, запоминаются между сеансами.
- **Аудио-пиковый фильтр (APF)** — узкий звуковой пиковый фильтр для CW, который
  усиливает биение (по частоте вашего тонального сигнала/sidetone), вытягивая
  слабые сигналы из шума. Включается, вместе с настройкой полосы (остроты) и
  усиления, в Configure → RX-N; работает только в режимах CW. Запоминается по
  приёмнику.
- **Громкость / mute / шумоподавление по порогу (squelch)** — уровень слышимого
  выхода и squelch для каждого приёмника. Регулятор **SQL** учитывает режим: в FM
  это шумовой squelch, в остальных режимах — амплитудный/речевой squelch, который
  глушит канал, пока сигнал не превысит порог. В нижнем положении squelch полностью
  выключен (звук проходит всегда).
- **Суб-приёмник (SUBRX)** — второй демодулятор внутри одного блока приёмника,
  включается кнопкой **SUBRX** на VFO; у него своя частота (VFO B), режим, фильтр
  и AGC. Основной приём идёт в левый канал, суб — в правый; ползунок
  **Sub-RX mix (split↔mono)** в настройках приёмника плавно сводит их от такого
  разделения по каналам до одинакового моно в обоих ушах. Состояние (вкл/выкл и
  положение микса) запоминается между запусками.
- **Diversity (разнесённый приём)** *(экспериментально — требует проверки на
  реальном оборудовании).* Складывает два когерентных потока ADC с регулируемым
  усилением/фазой, чтобы подавить локальную помеху или бороться с замираниями.
  Живёт на странице **Configure → Diversity**: галочка **Enable diversity**
  (недоступна на устройствах, которые это не умеют) включает режим — добавляет
  скрытый второй приёмник и микшер — рядом с регуляторами усиления/фазы и
  предупреждением. Только Protocol 1, нужен аппарат с двумя приёмниками/ADC; на
  железе в этом форке пока не проверено.
- **Споты DX-кластера** — когда подключён DX-кластер (см. Configure → Network),
  входящие споты рисуются на панадаптере приёмника короткой цветной отметкой с
  позывным, окрашенной по территории DXCC. **Левый клик по метке спота** сразу
  перестраивает приёмник на эту станцию (работает при обычной настройке, а также
  в ctun и freetune). Споты пропадают через 15 минут.

## 5. Темы водопада

Раскраска водопада выбирается из нескольких **тем**. Активная тема задаёт и цвета
отдельного FT8-водопада, так что оба индикатора выглядят согласованно.

## 6. Передача (TX)

Для радио HPSDR доступен полный тракт передачи: TX-фильтрация, CTCSS, EER и
измерители. PureSignal (адаптивная предыскажающая коррекция, Protocol 1) —
опция сборки. Передача через HackRF реализована (полудуплекс) по SoapySDR.
Ключевание — MOX, PTT или назначенным действием MIDI/клавиатуры.

**Обработка речи на передачу (Configure → TX).** Полный тракт обработки:
**CESSB** (контроль выбросов огибающей SSB), **CFC** — 5-полосный непрерывный
частотный компрессор (200 / 1 к / 2 к / 3 к / 4 к Гц с предкомпрессией и
предыскажением), **фазовый ротатор** (уменьшение асимметрии голоса, настраиваемые
частота среза и число ступеней) и **10-полосный графический эквалайзер** на
передаче и на приёме. Поступенчатые измерители **Leveler / CFC / Compressor**
(снижение усиления, дБ) рисуются под линией ALC на панораме передачи во время
передачи. *Это собрано и проверено на «фейковом» устройстве, но пока не проверено
в эфире — в этом форке нет передающего оборудования.*

## 7. Декодеры и FT8 / FT4

В модуле **Decode** на нижней панели есть **селектор декодера**. По умолчанию не
работает ни один декодер — выберите нужный, чтобы его запустить. Селектор
показывает только декодеры, применимые в текущем режиме: **DIGU / DIGL** —
**Off / FT8 / FT4 / SSTV / WEFAX**; **NFM (FMN)**, где применим только SSTV
(SSTV VHF/МКС по узкополосной ЧМ), — только **Off / SSTV**. Декодеры изображений
(SSTV, WEFAX) описаны в §8; FT8/FT4 — ниже. Выбор запоминается между сессиями.

В **цифровых режимах (DIGU/DIGL)**, а также пока работает любой декодер, **все
блоки, меняющие форму сигнала, автоматически обходятся** для этого приёмника — все
четыре режима NR (NR/NR2/NR3/NR4), бланкеры (NB/NB2), авто-режектор (ANF),
спектральный бланкер (SNB) и ручные режекторные фильтры. Они рассчитаны на слух и
искажают сигнал, нужный модему/декодеру (или внешней программе через VAC/TCI);
остаётся только то, что нужно декодеру, — демодуляция, полосовой фильтр и АРУ. Ваши
настройки сохраняются (индикаторы на VFO остаются) и снова вступают в силу, как
только вы выходите из цифрового режима и останавливаете декодирование.

В MacHPSDR встроен движок FT8/FT4 (внешний WSJT-X не нужен): выберите **FT8** или
**FT4** в селекторе, когда активный приёмник в **DIGU**.

- **Декодер** — децимирует демодулированное аудио, накапливает 15-секундные (FT8)
  или 7.5-секундные (FT4) UTC-слоты и декодирует их в фоне, независимо от
  громкости/mute прослушивания.
- **Компактный вывод** — по умолчанию нижняя панель показывает небольшой блок
  декодов/QSO. **Show FT8 Panel** (модуль SETUP) открывает полную панель вместо
  второго приёмника.
- **FT8-панель** — селектор протокола (FT8/FT4), смещение/слот TX, опция
  направленного CQ, колонка сообщений Tx1–Tx6 и прокручивающийся список
  активности диапазона (строки CQ — зелёные, вызовы вам — жирным, фильтр «только
  CQ», двойной клик по строке — начать QSO с этой станцией). Новые DXCC-территории
  подсвечиваются (золотой — новая территория вообще, синий — новая на этом
  диапазоне), название страны — во всплывающей подсказке.
- **Авто-QSO** — при **Enable Tx** + **Auto Seq** движок ведёт стандартный обмен
  WSJT-X (CQ → грид → рапорт → R-рапорт → RR73 → 73) и пишет завершённые QSO в
  `~/.local/share/machpsdr/ft8_log.adi` (ADIF). Доступны и ручные Tx1–Tx6 и
  свободный текст.
- **FT8-водопад** — отдельная спектрограмма высокого разрешения полосы FT8
  появляется справа от РЧ-водопада, пока открыта панель. Левый клик по ней задаёт
  смещение TX на свободной частоте.
- **Идентификация станции** — позывной и грид задаются в **Configure → FT8**;
  Enable Tx недоступен, пока оба поля не заполнены.
- **Сетевое логирование** — завершённые QSO можно отправлять в логгер (Log4OM,
  N1MM+, JTAlert, GridTracker) как WSJT-X-совместимые UDP ADIF-сообщения
  (Configure → FT8).
- **PSK Reporter** — каждую декодированную станцию можно отправлять на карту PSK
  Reporter. Передача идёт только когда заданы и позывной, и грид (Configure → FT8).
- **DXCC** — подсветка «new one» использует `cty.dat` от AD1C; кнопка **Reload
  cty.dat** и статус — в Configure → FT8.

**CW-декодер (морзянка).** В режимах CW (CWL/CWU) модуль Decode предлагает
селектор **Off / CW**. При выборе **CW** аудио приёмника декодируется в текст:
декодер захватывает тон манипуляции, автоматически подстраивается под скорость
передачи и превращает точки и тире в буквы. Нажмите **Show CW**, чтобы открыть
панель (вместо второго приёмника, как панели SSTV/FT8) с прокручивающимся
декодированным текстом, живым показанием WPM / частоты тона и кнопкой
**Clear**. Декодированный текст также попадает в вывод модуля Decode.
Декодирование полностью автоматическое — внешняя программа не нужна. (Лучше
всего работает на одиночном, хорошо настроенном CW-сигнале в достаточно узком
фильтре; сильный QRM или несколько накладывающихся сигналов исказят текст.)

Панель Show CW также позволяет **передавать** CW. В её строке TX — восемь
**сохранённых сообщений** (кнопки M1…M8), поле **свободного текста**, кнопки
**Send** и **Stop** и регулятор **WPM**. Сообщения редактируются в
**Configure → CW**; токен `%C` разворачивается в позывной вашей станции.
Передача превращает текст в манипулируемый сайдтон на заданной скорости, весе
и тоне, автоматически манипулирует передатчиком в CWL/CWU и снимает
манипуляцию по завершении сообщения. *(Кодер проверен внутренним циклом
кодирование → декодирование; сам эфирный сигнал пока не подтверждён — у этого
форка нет передающего оборудования.)*

Также есть **программный ямбовый манипулятор**. Режим манипулятора (Straight /
Mode A / Mode B), скорость, вес и реверс парного ключа задаются в
**Configure → CW**. Роль двух половин парного ключа играют клавиши **`[`**
(точка) и **`]`** (тире) — они действуют только пока активный приёмник
находится в CWL/CWU — либо **MIDI**-контроллер, привязанный к действиям
CW-left / CW-right (привязывайте их с опцией ONOFF, чтобы передавались и
нажатие, и отпускание). Одновременное нажатие обеих половин даёт настоящее
ямбовое чередование с памятью точки/тире; Mode B добавляет дополнительный
завершающий элемент. Манипуляция прекращается (а передатчик снимает
манипуляцию через небольшую задержку) при отпускании парного ключа. *(Тайминг
режимов A/B проверен автономным модульным тестом; поведение в эфире с реальным
парным ключом не проверено — здесь нет ни передающего оборудования, ни
физического ключа.)*

**HFDL — авиационная КВ-линия данных.** HFDL (ARINC 635) —
это линия коротких сообщений, которой авиалайнеры пользуются над океанами, когда
УКВ уже не достаёт: наземные станции передают свой статус, самолёты
регистрируются и отключаются, а сообщения ACARS — доклады о местоположении,
планы полёта, служебный трафик — идут в обе стороны. MacHPSDR декодирует это «из коробки».

Переведите приёмник в **DIGU** и выберите **HFDL** в селекторе
Decode; кнопка **Show HFDL** открывает панель (в слоте второго приёмника, как у
остальных декодеров) с расшифрованными сообщениями, а блок Decode показывает
уровень сигнала, число кадров и поток символов. Настраивайтесь как на любой
цифровой сигнал в USB — декодер рассчитан на стандартный сдвиг несущей 1440 Гц,
то есть на шкале ставится *назначенная* частота канала. Что вы увидите:

- **Сквиттеры** — периодическая передача каждой наземной станции: название,
  синхронизация с UTC, версия системной таблицы и используемые сейчас частоты.
- **Регистрация / отключение** — **адрес ICAO** самолёта при входе на станцию и
  выходе с неё, а также присвоенный ему короткий идентификатор. В последующих
  сообщениях этого борта адрес ICAO подставляется автоматически.
- **Доклады о позиции, характеристиках и частотах** — идентификатор рейса,
  широта, долгота, время UTC, используемые станция и частота, а также частоты,
  на которых борт слышит станции.
- **Текст сообщений ACARS** — регистрация борта, метка, номер рейса, номер
  сообщения и само тело сообщения.

Названия станций и частоты каналов берутся из встроенной таблицы, поэтому доклад
про «слот частоты 1» показывается настоящими килогерцами. Содержимое CPDLC и
ADS-C внутри ACARS не расшифровывается (текст показан как есть), а сообщения,
разбитые на несколько блоков ACARS, показываются поблочно, без сборки.

*(Проверено на реальной эфирной записи: на записи 11387 кГц наземной станции
Riverhead (Нью-Йорк) декодер выдал сквиттеры, аплинк с двумя подтверждениями
регистрации и настоящими адресами ICAO, доклады о позиции и характеристиках
бортов, а текст ACARS совпал с выводом эталонного декодера для того же кадра.)*

## 8. SSTV и WEFAX — изображения и метеофакс

Два самостоятельных декодера изображений делят селектор модуля Decode с FT8. Как и
FT8, они работают на полном уровне аудио независимо от громкости/mute, так что
можно декодировать беззвучно. Каждый открывает панель изображения вместо второго
приёмника.

### SSTV — аналоговые изображения (приём и передача)

Выберите **SSTV** в селекторе и нажмите **Show SSTV**, чтобы открыть панель. SSTV
работает в **DIGU/DIGL** для **КВ** SSTV (SSB — частота вызова 14.230 МГц) и в
**FMN** для **УКВ/МКС** SSTV (МКС передаёт на **145.800 МГц ЧМ**, поэтому для
Robot 36 / PD120 используйте FMN).

- **Приём** — декодер автоматически определяет режим по VIS-заголовку и рисует
  картинку построчно. Поддержаны: **Martin M1/M2**, **Scottie S1/S2/DX**,
  **Robot 36/72**, **PD50/90/120/160/180/240** — это покрывает SSTV с МКС
  (Robot 36 MAI-75, PD120 события ARISS). **Auto** работает даже на ЧМ, где
  де-эмфазис смазывает VIS-заголовок, распознавая режим по периоду строки
  синхроимпульсов, так что обычно ничего выбирать не нужно. Есть переопределение
  режима (**Mode**), автоматический корректор наклона с ручной подстройкой
  **Slant ±** поверх и **AFC** (отслеживает доплер МКС). **Save** пишет PNG в
  `~/.local/share/machpsdr/sstv/`; **Clear** сбрасывает.
- **Передача** — строка **Tx** панели: выберите **режим**, **Load…** любое
  изображение (вписывается в геометрию режима с сохранением пропорций — поля
  дополняются чёрным, не растягивается — и показывается предпросмотр) и нажмите
  **Send**. Передаётся стандартный VIS-заголовок плюс строки развёртки через
  обычный телефонный TX-тракт, поэтому работает на любом протоколе — DIGU/DIGL для
  КВ, FMN для УКВ ЧМ. MOX ключуется автоматически на длину картинки (её отслеживает
  индикатор прогресса) и снимается по завершении, со сторожевым таймером; **Stop**
  прерывает.

### WEFAX — КВ-радиофакс / метеокарты (только приём)

Выберите **WEFAX** в селекторе (в **DIGU/DIGL** — КВ-факс идёт по USB) и нажмите
**Show WEFAX**. В отличие от SSTV, WEFAX — это *непрерывная* развёртка (метеокарты
и спутниковые снимки со станций вроде DWD Hamburg, NMG/NHC, Northwood, …), поэтому
картинка прокручивается по мере приёма, а не является кадром фиксированной высоты.
Он рассчитан на то, чтобы просто работать:

- **Auto-phase** (по умолчанию вкл.) находит повторяющийся вертикальный ориентир
  факса (его чёрное поле) и сам подтягивает его к левому краю, так что картинка
  выравнивается сама, без кликов.
- **Auto-start** (по умолчанию вкл.) распознаёт стартовый тон передачи (300 Гц для
  IOC 576 / 675 Гц для IOC 288), чтобы начать новую страницу и инициализировать AFC.
- **LPM** (60/90/**120**/240) и **IOC** (**576**/288) задают тайминг строки;
  120 lpm / IOC 576 — стандарт метеофакса и значение по умолчанию.
- **AFC-автоэкспозиция** держит белый фон на правильном уровне (уход частоты не
  «зашумит» картинку в серость), а **Denoise** убирает импульсные точки, сохраняя
  тонкие линии карты. **Invert** переворачивает инвертированный (не та боковая
  полоса) сигнал в позитивное чёрное-по-белому.
- Вручную: снимите Auto-phase и **кликните по изображению**, чтобы задать левое
  поле, **Start** — начать страницу, **Slant ±** — убрать наклон.
- **Save** пишет PNG в `~/.local/share/machpsdr/wefax/`; **Clear** начинает заново.

Настройте станцию в **DIGU/USB** примерно на 1.9 кГц ниже назначенной частоты
(чтобы чёрное легло на 1500 Гц, белое — на 2300 Гц) и дайте **широкий фильтр
приёма (~1.9 кГц, напр. 1000–2900 Гц)** — слишком узкий смазывает быстрые переходы
чёрное↔белое.

## 9. Рекордер I/Q + аудио

Кнопка **Record** (модуль SETUP) пишет активный приёмник в
`~/.local/share/machpsdr/`:

- `rec_<UTC>_iq.wav` — эфирный I/Q на частоте дискретизации приёмника. Формат —
  тот же 16-битный стерео, что читает плеер `--faker`, поэтому запись можно
  **проиграть обратно через fake-устройство**.
- `rec_<UTC>_af.wav` — чистое демодулированное аудио 48 кГц.

Какие потоки писать и папку вывода задают в **Configure → Audio**.

## 10. Конфигурация

Диалог **Configure** делит настройки на страницы: Radio, Receiver, Transmitter,
MIDI, Bookmarks, Diversity, PA, EER, PureSignal, **FT8**, **Recording** и
**Misc**. Все настройки автоматически сохраняются в файл свойств для конкретного
устройства в `~/.local/share/machpsdr/` и восстанавливаются при следующем
запуске.

На странице **Misc** находятся выбор цветовой схемы, свои подписи кнопок
аттенюатора, параметры вещательного FM и **Frequency Calibration (PPM)**:
выберите станцию точного времени/частоты (RWM, WWV, CHU, BPM на КВ; MSF, DCF77,
Droitwich на ДВ) и нажмите **Calibrate**, чтобы измерить её несущую и выставить
коррекцию генератора автоматически, **Tune** — чтобы свести на нулевые биения на
слух, либо введите значение вручную.

**DX-кластер (Configure → Network).** Подключение к telnet DX-кластеру: введите
хост/IP, порт и позывной для входа (оставьте поле логина пустым, чтобы
использовать позывной станции со страницы FT8), затем поставьте галочку
**Connect to DX cluster** — строка состояния показывает статус соединения.
**Show spots on panadapter** включает/выключает наложение спотов на
панадаптере. Входящие споты `DX de …` сохраняются и показываются на
панадаптере приёмника, окрашенные по территории DXCC, клик по споту
перестраивает приёмник на него; клиент переподключается автоматически при
обрыве связи.

**Сервер TCI (Configure → Network).** MacHPSDR может работать как управляющий
сервер **TCI** (Expert Electronics), чтобы внешние логгеры и скиммеры — Log4OM,
N1MM+, SkookumLogger и другие программы, понимающие TCI — задавали и отслеживали
состояние трансивера по сети, без виртуального COM-порта или аудиокабеля.
Поставьте галочку **Enable TCI server**, при необходимости измените **порт** (по
умолчанию 40001) и укажите в программе адрес `ws://<этот-компьютер>:40001`.
Строка состояния показывает, слушает ли сервер и сколько клиентов подключено.
Когда клиент меняет VFO, режим, PTT, RIT, XIT или сплит — трансивер следует за
ним, а когда вы перестраиваете частоту, меняете режим или RIT/XIT/сплит локально
— изменение рассылается всем подключённым клиентам, чтобы они оставались
синхронными. Одновременно может быть
подключено несколько клиентов. Клиент также может запросить **живой поток I/Q**
(`iq_start`): MacHPSDR начнёт отдавать эфирный I/Q бинарными кадрами TCI, чтобы
внешний CW/RTTY-скиммер или панорама работали от этого приёмника без
виртуального аудиокабеля — для этого запускайте приёмник на 96 или 192 кГц, так
как TCI считает потоком I/Q только частоту выше 48 кГц. Клиент также может
запросить **поток RX-звука** (`audio_start`), чтобы получать демодулированное
аудио, и присылать **TX-звук** обратно — тогда внешняя программа цифровых видов
может ключевать и модулировать трансивер по TCI вместо виртуального аудиокабеля.
Звуковые потоки по умолчанию идут на 48 кГц, но клиент может запросить другую
частоту (MacHPSDR передискретизирует). Если запущено несколько приёмников,
каждый доступен как отдельный TCI-*trx*. Клиент также может передавать телеграф:
команда `cw_msg` ключует встроенный кейер и отправляет текст (скорость — из
настроек CW либо через `cw_macros_speed`). *Пути передачи (звук и CW) в эфире не
проверялись (нет передающего железа).*

## 11. Управление MIDI и клавиатурой

Любое глобальное **действие** (настройка, режим, фильтр, AGC, MOX, зум, …) можно
назначить на сочетание клавиш или контроллер MIDI через **MIDI learn**. На macOS
MIDI работает через CoreMIDI. Назначения сохраняются в `midi.props`.

## 13. Тест без оборудования (I/Q Player)

Синтетический SDR доступен в списке устройств как **«I/Q Player»** (всегда
последним): выберите его и нажмите **Start Radio**. Он зацикливает 16-битный
стерео I/Q WAV через полный тракт приёма/декодирования либо играет синтетический
шум+тоны, если файл не задан. **Файл выбирается в Configure → Radio** (блок
*I/Q Player*: *Choose I/Q File…* / *Synthetic*) — выбор запоминается и его можно
менять **на лету во время воспроизведения**. Файл также можно передать в
командной строке — `--faker ft8.wav` (при этом диалог выбора пропускается) — или
задать `MACHPSDR_FAKE_IQ`; файл из командной строки имеет приоритет, а без источника
берётся `iq.wav`. Запись пересемплируется к частоте приёмника и автоцентрируется к
нулю, затем зацикливается. При инверсии боковой полосы включите **Swap I & Q** в
диалоге радио, чтобы зеркально отразить спектр на лету. Это рекомендованный способ
попробовать декодирование FT8, воспроизведение записей рекордера и интерфейс без
радио.
